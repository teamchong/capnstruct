`capnstruct` compiles declarative TypeScript struct schemas into monomorphic `DataView` classes using standard **C / Rust `#[repr(C)]` memory layout** plus a relative-offset tail arena for variable-length UTF-8 strings (`str`), slices (`slice(T)`), and **nullable/circular pointers (`ref(() => Node)`)**.
