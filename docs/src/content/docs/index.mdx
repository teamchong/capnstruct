`capnstruct` is the missing shared-memory struct layer between JavaScript, Web Workers, and Rust/Go WebAssembly — compiling declarative TypeScript schemas into **C / Rust `#[repr(C)]` memory layouts** with a relative-offset tail arena for variable-length strings (`str`), slices (`slice(T)`), and cyclic pointers (`ref('Node')`).
